# 牟成露 · 视觉设计作品集

这是牟成露的个人视觉设计作品集网站，聚焦品牌视觉、文化海报、公益设计与手绘创作。网站以深色编辑式版面呈现 8 组项目、19 件作品，并针对桌面端和移动端进行了响应式设计。

## 作品分类

- 品牌设计：Pao泡宠物品牌系统、PawNest 吾窝
- 视觉与海报：活路儿民艺 IP、敦煌文旅季、共生环境议题
- 手绘创作：动物与东方意象、器物与想象、人物素描研究

所有线上图片均经过分辨率优化、元数据清理和署名水印处理。作品版权归牟成露所有，未经许可请勿转载或商用。

## 技术与交互

- Next.js 16 + React 19 + TypeScript
- 静态导出与 GitHub Pages 自动部署
- 项目筛选、作品灯箱、键盘切换、滚动进度与视差动效
- 响应式排版与 `prefers-reduced-motion` 无障碍适配

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build:pages
```
